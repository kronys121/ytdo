# ytdo

Скачивание видео и Shorts с YouTube с выбором качества (Windows).

## Установка

1. Запустите `install.bat`. Он найдёт Python (или поставит его через winget), создаст окружение `.venv` и установит:
   - `yt-dlp` - загрузчик;
   - `deno` - JS-движок, нужен yt-dlp для получения всех форматов YouTube;
   - `imageio-ffmpeg` - ffmpeg для склейки видео и звука.
2. Если Python ставился через winget, запустите `install.bat` повторно.

## Использование

1. Запустите `start.bat`.
2. Вставьте ссылку (обычное видео, `youtube.com/shorts/...`, `youtu.be/...`).
3. Выберите качество из списка (Enter = лучшее) или "Только звук".

Файлы сохраняются в `Downloads\Videos`, `Downloads\Shorts`, `Downloads\Audio`.
Видео склеивается в mp4; при одинаковом разрешении предпочитается H.264 + AAC.

## Обновление

YouTube часто меняется. Если начались ошибки, запустите `install.bat` ещё раз - он обновит yt-dlp.
